GitOps Kubernetes Platform — Flux, Istio, and End‑to‑End Cloud Pipeline

_____________________________________________________________________________________________

This repository contains the complete GitOps configuration for a production‑grade Kubernetes
platform deployed on Azure Kubernetes Service (AKS). The cluster is fully managed through Flux,
secured with Keycloak, and routed through Istio, with a complete CI/CD pipeline enabling automated
application delivery. All infrastructure, workloads, and platform services are defined declaratively
using YAML, JSON, and Terraform, ensuring consistent, repeatable, and auditable cloud operations across the environment.
